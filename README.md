# 🚀 SmartPunish — Minecraft Moderation Plugin

---

## 🇷🇺 Русский язык

### 📌 Описание проекта
**SmartPunish** — это высокопроизводительный, современный и надежный плагин модерации, созданный специально для серверов Minecraft. Плагин разработан с акцентом на минимальное потребление ресурсов и максимальную защиту сервера от нарушителей.

> 🔒 **Информация о типе распространения:**  
> Данный проект **НЕ является Open Source** (исходный код закрыт). Этот репозиторий используется исключительно для публикации официальных готовых сборок (`.jar`), ведения технической документации и сбора отчетов об ошибках (Issues).  
> **Плагин полностью бесплатен для публичного использования.**

---

### 📦 Инструкция по установке
1. Перейдите на страницу **[Релизов](../../releases)** в этом репозитории.
2. Скачайте последнюю версию файла `SmartPunish.jar`.
3. Поместите скачанный файл в папку `/plugins/` вашего сервера Minecraft.
4. Перезапустите сервер или выполните команду загрузки плагинов.

---

### 🔧 Технические требования
* **Версия Minecraft:** `1.21.4` (поддерживаются ядра Paper, Purpur, Spigot).
* **Версия Java:** `Java 21` или выше.
* **База данных:** H2 / SQLite / MySQL (опционально).

## 🇬🇧 English Language

### 📌 Project Overview
**SmartPunish** is a high-performance, modern, and reliable moderation plugin designed specifically for Minecraft servers. Built with performance in mind, it guarantees zero TPS drops while maintaining powerful management tools for server staff.

> 🔒 **Distribution & Source Code Notice:**  
> This project is **NOT Open Source** (the source code is proprietary and private). This repository serves solely as an official distribution hub for compiled `.jar` binaries, documentation, and bug tracking.  
> **The plugin is free for public use.**

---

### 📦 Installation Guide
1. Navigate to the **[Releases](../../releases)** section of this repository.
2. Download the latest `SmartPunish.jar` release.
3. Place the downloaded `.jar` file into your server's `/plugins/` directory.
4. Restart your server to load the plugin.

---

### 🔧 System Requirements
* **Minecraft Version:** `1.21.4` (Paper, Purpur, Spigot).
* **Java Version:** `Java 21` or higher.
* **Database Support:** H2 / SQLite / MySQL (optional).
